About this project

A small neuroengineering project: classifying 12 finger/thumb gestures from surface EMG signals, as a first step toward getting a feel for how EMG-driven ("myoelectric") prosthetic hand control works — the broader problem this project sits within.

Dataset: NinaPro DB1, Subject 1, Exercise A — 10-channel surface EMG, 12 gestures, 10 repetitions each. Worth being upfront about the scale: this is one subject, one recording session — small enough that results here shouldn't be read as claims about how any of these models would perform on a different person's EMG. Full discussion of that and other limitations is in the project notebook (available on GitHub).

How this was built: this is a learning project, and part of that learning was being deliberate about how I used AI along the way. I used Claude to understand EMG/ML concepts and get my first models running, but shifted partway through to writing the code myself from explained instructions — the goal being that I acquire new knowledge and skills and that I can actually explain and recreate every part of this project by myself.
